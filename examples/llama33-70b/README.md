# Osprey on Llama-3.3-70B-Instruct

Reproduces the Osprey column of **Table 1**. The drafter starts from the same
pretrained backbone as Qwen3-8B; the target is dense and served in bf16 at tp=4
on one 8-GPU node. The model is gated on the Hub: accept its license, then
`hf auth login`.

Run everything from the repository root after
[Installation](../../README.md#installation), with `OSPREY_OUTPUT` set.

## Training

### Data

Download the released split (100,000 training conversations, 512 held out) and
the backbone:

```bash
hf download BobbieBieee/Osprey-Speculative-Decoding \
  --include "data/perfectblend_*_llama33_70b.jsonl" "pretrained/qwen3-4b-2layer-fineweb-55k/*" \
  --local-dir osprey
```

Or build it. The source is
[frankleeeee/PerfectBlend-Regenerated-Llama-3.3-70B-Instruct](https://huggingface.co/datasets/frankleeeee/PerfectBlend-Regenerated-Llama-3.3-70B-Instruct)
— Open-PerfectBlend prompts with responses regenerated by the target, 1,419,775
records. Number the records in file order, `random.seed(42)` then
`random.shuffle`, and take the first 100,000 as train and the next 512 as eval.
Multi-turn conversations are kept as-is.

### Convert

```bash
python scripts/osprey/convert_checkpoint.py \
  --architecture qwen3 --target llama33-70b \
  --source-checkpoint osprey/pretrained/qwen3-4b-2layer-fineweb-55k \
  --output-dir "$OSPREY_OUTPUT/qwen3-2l-init-llama33-70b"
```

The preset sets hidden size 8192 and the 128,256-token Llama 3 vocabulary. The
alignment report should read `direct: 109566, single: 297, averaged: 18393,
unmapped: 0`; on the released backbone this reproduces the paper's Stage-3
output bit for bit.

### Train

```bash
export OSPREY_DRAFT_INIT="$OSPREY_OUTPUT/qwen3-2l-init-llama33-70b"
export OSPREY_LLAMA_DATA=$PWD/osprey/data/perfectblend_train_100k_llama33_70b.jsonl
bash examples/llama33-70b/train.sh
```

8 GPUs, target tp=4, lr 1e-4, TTT length 5, sequence length 4096, `llama3`
chat template, 3 epochs. Each GPU is one draft data-parallel rank, so an epoch
is 12,500 steps and the run ends at **37,500**. The checkpoint to evaluate is
`$OSPREY_OUTPUT/llama33-70b/osprey/perfectblend/epoch_2_step_37500`. Measured on
8×H100 80 GB: 50–62 GB per GPU, about 1.5 s per step.

## Evaluation

Evaluation takes 4 GPUs (the target in bf16 at tp=4) and scores one drafter on
all five domains: all 512 prompts per domain,
`(batch, steps, topk, draft_tokens) = (1, 5, 1, 6)`, greedy.

### Data

The five evaluation splits are the Qwen3-8B ones: the benchmarks read only the
prompts, so they serve any target.

```bash
hf download BobbieBieee/Osprey-Speculative-Decoding \
  --include "data/*_eval_512_qwen3_8B_4096.jsonl" --local-dir osprey
export OSPREY_DATA=$PWD/osprey/data
```

### Your own checkpoint

Point the script at the final Stage-4 directory written by `train.sh`; any
intermediate `epoch_*_step_*` directory works the same way:

```bash
bash examples/llama33-70b/eval.sh "$OSPREY_OUTPUT/llama33-70b/osprey/perfectblend/epoch_2_step_37500"
```

### Released checkpoint

```bash
hf download BobbieBieee/Osprey-Speculative-Decoding \
  --include "llama33-70b/osprey/*" --local-dir osprey
bash examples/llama33-70b/eval.sh osprey/llama33-70b/osprey
```

Results land in `$OSPREY_OUTPUT/results/<name>/` as JSON plus a flat CSV, where
`<name>` is `osprey-perfectblend` for the trained checkpoint and `osprey` for the
released one; set `RESULT_NAME` to choose it yourself.
